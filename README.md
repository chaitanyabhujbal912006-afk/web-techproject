# Web Technology Projects

This repository contains Web Technology assignments and projects:

## Projects

1. **[Assignment 7 - TypeScript Weather Dashboard](./Assignment7_TypeScript_Weather_Dashboard)**
   - Interactive Weather Dashboard built with TypeScript, HTML5, and CSS3.
   - Fetches real-time weather metrics, forecasts, and environmental indicators.

2. **[Assignment 8 - Zustand & TanStack Data Fetching](./Assignment8_Zustand_TanStack_Data_Fetching)**
   - React application demonstrating modern state management with Zustand.
   - Integrated with TanStack Query (React Query) for asynchronous data fetching, caching, and toast notifications.

3. **[Assignment 9 - Next.js Rendering Strategies](./Assignment09_NextJS_Rendering_Strategies)**
   - Next.js application comparing core rendering paradigms: SSR (Server-Side Rendering), SSG (Static Site Generation), and ISR (Incremental Static Regeneration).
